🎯 What this skill does: Every time you ask Claude to document something, it will automatically generate white-background HTML files using the professional style from your 4_layer_framework.html — not dark markdown.

How to Install the AI Docs Skill

This skill teaches Claude inside Antigravity to always generate documentation in the style you love — white background, professional HTML, with code examples, tool comparisons, and architect's reasoning for every decision.

Step 1 — Find the skill folder

1

Locate skill-ai-docs/ in your workspace folder

It was created inside your project folder alongside your other documentation files. It contains one file: SKILL.md

your-project/
├── 4_layer_framework.html        ← white bg HTML (reference)
├── all_files.html                ← 7-topic deep dive
├── SOLUTION_ARCHITECT_FUNDAMENTALS.md
├── skill-ai-docs/               ← 📁 THE SKILL FOLDER
│   ├── SKILL.md                 ← skill instructions
│   └── HOW_TO_INSTALL.html      ← this file

Step 2 — Copy to Antigravity's skills directory

2

Option A — Antigravity has a skills UI

Open Antigravity → Settings → Skills (or Plugins) → "Add Skill" or "Import Skill" → point to the skill-ai-docs/ folder.

2

Option B — Copy manually (Mac/Linux)

# Find where Antigravity stores skills — try these locations:
ls ~/.antigravity/skills/
ls ~/.config/antigravity/skills/
ls ~/Library/Application\ Support/Antigravity/skills/

# Copy the skill folder there:
cp -r /path/to/your/project/skill-ai-docs/ ~/.antigravity/skills/
2

Option C — Claude Code / Cowork (already works here!)

If you're in Cowork mode (which you are right now), skills work differently — the instructions live in the SKILL.md and Claude reads them automatically when you ask for documentation.

To make it available in Cowork permanently: copy the skill-ai-docs/ folder to your .skills/skills/ directory inside your workspace.

Step 3 — Restart Antigravity

3

Reload skills

After copying, restart Antigravity or reload skills (Settings → Skills → Refresh). The skill will appear as "ai-docs" in the skills list.

Step 4 — Test it

4

Ask Claude to document something

Try any of these prompts — Claude will automatically use the skill and generate properly styled HTML:

"create a file explaining my FastAPI app architecture"
"document this codebase as HTML"
"explain the 4 layers of this system with examples"
"make a white background HTML guide for [any topic]"
"create docs with architect decisions and tool comparisons"

What you'll always get

Every documentation request will produce:
🎨
White background HTML — light theme, professional, browser-renderable. No more dark IDE colors.
🏗️
4-layer structure — Interface → Orchestration → Knowledge → Infrastructure. Consistent across every project.
💻
Code examples for every concept — no concept without code. Comments explain WHY, not just what.
🔧
Tool comparison tables — at every layer, shows the chosen tool, alternatives, and the architect's reason for choosing.
🗺️
End-to-end pipeline trace — a single request traced through all 4 layers with latency breakdown.
✅
Production checklist — per-layer checklist of what to verify before going live.
